# Büyük Zekâlarla Yapay Zekâyı Keşfet • YAREN

Çocuklar için hazırlanmış, tarayıcıda çalışan interaktif Yapay Zekâ Okuryazarlığı portalı.

Bu portalda öğrenciler; Türk-İslam bilim ve düşünce mirasından seçilen büyük isimler ile günümüzün Türk bilim insanlarını tanıyarak yapay zekânın temel kavramlarını oyunlar, mini laboratuvarlar, görevler ve etkileşimli deneyimler üzerinden keşfeder.

## Proje Amacı

Bu çalışma, çocuklara yapay zekâyı “sihirli bir makine” gibi değil; veriyle öğrenen, insan aklına yardımcı olan, sorumluluk ve etikle kullanılması gereken bir araç olarak anlatmak için tasarlanmıştır.

Portalın temel hedefleri:

- Yapay zekâ okuryazarlığını çocuklara uygun bir dille öğretmek
- Bilim insanlarını yapay zekâ konularıyla pedagojik olarak ilişkilendirmek
- Tarihî ve güncel bilim insanlarını birlikte sunmak
- Çocukların öğrenirken deneme, hata yapma, keşfetme ve üretme deneyimi yaşamasını sağlamak
- Yapay zekâ, veri, algoritma, görsel tanıma, sağlıkta YZ, dil modelleri, etik YZ ve bilimsel simülasyon gibi konuları somutlaştırmak

## Kurulum

Projeyi çalıştırmak için:

1. Bu repoyu indirin veya klonlayın.
2. `index.html` dosyasını tarayıcıda açın.

```bash
git clone https://github.com/ayhanbzkrt/biliminsanlariveyapayzeka.git
cd biliminsanlariveyapayzeka
open index.html
```

## GitHub Pages ile Yayınlama

GitHub Pages üzerinden yayınlamak için:

1. GitHub reposuna girin.
2. `Settings` bölümünü açın.
3. `Pages` sekmesine girin.
4. Source alanında `Deploy from a branch` seçin.
5. Branch olarak `main`, klasör olarak `/root` seçin.
6. Kaydedin.

Yayın adresi şu biçimde olur:

```text
https://ayhanbzkrt.github.io/biliminsanlariveyapayzeka/
```
